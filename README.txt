CS 310 — WEB DEVELOPMENT PRESENTATION WEBSITE
================================================

OPEN LOCALLY:
1. Double-click index.html.
2. The website opens in Chrome, Edge, or another modern browser.
3. Use the Next / Previous buttons to move between five slides.
4. Use Speaker notes to read your detailed presentation script.
5. Fullscreen is available at the top-right.

KEYBOARD SHORTCUTS:
- Right arrow / space: Next slide
- Left arrow: Previous slide
- 1–5: Jump to a slide
- N: Open or close speaker notes
- F: Toggle fullscreen

WHAT IS INCLUDED:
- Five polished presentation slides
- Working HTML required-field validation example
- Interactive desktop/mobile CSS layout preview
- JavaScript customer submission demo with DOM updates
- On-screen speaker notes and common professor questions
- Presentation timer and progress bar
- Mobile-friendly presentation mode

This standalone index.html uses no external libraries or network connections.
The live Sweet Crumbs link on the final slide requires internet access.
All demos use locally entered data; nothing is uploaded or sent to a server.

PUBLISH ONLINE (OPTIONAL):
- Create a NEW GitHub repository for this presentation.
- Upload index.html to its root.
- Enable GitHub Pages from Settings > Pages.
- Avoid replacing the files in your existing Sweet Crumbs repository.

Presentation duration target: about 5 minutes.
